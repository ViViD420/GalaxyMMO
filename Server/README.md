# Server

This directory is reserved for GalaxyMMO-owned server code and integration adapters.

Core3 is evaluated as an upstream candidate in a separate checkout; do not copy its source into this directory casually. Record the exact upstream commit, license review, build result, and network findings in `docs/CORE3_RECONNAISSANCE.md` before deciding how it is integrated.

Server code must own validation and authoritative outcomes for inventory, currency, combat, progression, crafting, and persistence.
